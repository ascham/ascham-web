# Contributing

## Bug reports are welcome

Email hello@ascham.app. Say what you did, what you expected and what
happened, with your browser and its version. If the bug needs a text to show
it, use one you made up or one in the public domain.

Never send a student's work, a pupil's name, any text that is not yours to
share, or a licence key. Email is not private: see the Contact page.

For a security problem, see `SECURITY.md`.

## Code contributions are not accepted

The source is published as a download from our site, and mirrored on
GitHub. There is no issue tracker, and the project takes no outside code:
pull requests and code sent by email are not used. Please don't spend time
on it.

Why, briefly:

- **Licensing.** Open source under the GNU AGPL, version 3: anyone can
  read, build, verify and change the code, and share changes under the same
  licence. All of the code has one owner, which keeps its licensing simple;
  outside code would need a contributor licence agreement, and the project
  has chosen not to ask for one.
- **Promises.** The app makes literal promises about what happens to a
  teacher's text (`PROMISES.md`), and every change is checked against them
  by the person who answers for them.

A suggestion is welcome by email, in words.
