Source

The source code of each release of Ascham, in two files: a git bundle of the public repository up to that release, with one commit and one tag for each release, and a tar.gz archive of the release's files.

How to build it, and check that it matches the site, is in README.md and VERIFY.md, inside each download.

Ascham 1.4.0: ascham-1.4.0.bundle, ascham-1.4.0.tar.gz

The same repository is mirrored on GitHub, at github.com/ascham/ascham-web. The files here are the reference: each release's tag names the same commit in both.
